# MotorPulseTest для ESP8266

Открой `ESP8266_GPIO5_MotorPulseTest.ino` в Arduino IDE и выбери свою **ESP8266** плату: например, NodeMCU 1.0 (ESP-12E Module) либо LOLIN(WEMOS) D1 R2 & mini. Нужен пакет **esp8266 by ESP8266 Community**. `ESP8266WiFi` входит в пакет; ESP32Servo и LEDC не используются.

**Выход: GPIO5 — контакт D1 на NodeMCU/Wemos D1 mini, уровень 3,3 В.** Это номер GPIO, а не контакт D5. На других платах используй контакт, соответствующий GPIO5; он должен быть выведен наружу.

GPIO5 подключается к сигнальному входу исследованного контроллера двигателя. Земля ESP8266 и контроллера должна быть общей. Сам двигатель получает питание через контроллер от внешнего источника. Этот сигнал не подключается непосредственно к двигателю; обычный L298N не распознаёт эти длительности как команды направления.

Сохраняются измеренные значения HIGH:

| Режим | Ширина HIGH |
| --- | --- |
| Нейтраль | 1400 мкс |
| Вперёд | 1418 мкс |
| Назад | 1374 мкс |

После включения: нейтраль 5 с. Затем постоянно: вперёд 3 с → нейтраль 2 с → назад 3 с → нейтраль 2 с. Нейтраль означает продолжающуюся выдачу импульсов 1400 мкс. Мотор начнёт двигаться автоматически; освободи привод/подними колёса перед включением.

По умолчанию частота 100 Гц. Можно заменить `PWM_FREQUENCY_HZ` на `200`: диапазон `analogWriteRange` пересчитается вместе с периодом, сохраняя заданные длительности HIGH. На 100 Гц период 10000 мкс, на 200 Гц — 5000 мкс.

В ESP8266 Arduino core PWM программный, на таймерных прерываниях. Он продолжает работать во время `delay()`. Wi-Fi выключен для уменьшения фоновой активности; записанные Wi-Fi настройки не перезаписываются. Параметры HIGH заданы с шагом 1 мкс, но это не гарантия отсутствия джиттера: фактическую форму сигнала нужно оценивать измерением, особенно при добавлении Wi-Fi/другой нагрузки.

Serial Monitor: 115200 baud. Выводит заданную команду и параметры сигнала. Для прекращения движения отключи силовое питание двигателя.

Версия для ESP32 остаётся отдельно в `../ESP32_GPIO19_MotorPulseTest/`. Старые GPIO19, GPIO23 и GPIO32 из неё здесь не используются. Скетч не компилировался и не запускался.

Источники: [ESP8266 Arduino core — PWM](https://arduino-esp8266.readthedocs.io/en/latest/reference.html#analog-output), [NodeMCU pin mapping](https://github.com/esp8266/Arduino/blob/master/variants/nodemcu/pins_arduino.h), [Wemos D1 mini pin mapping](https://github.com/esp8266/Arduino/blob/master/variants/d1_mini/pins_arduino.h).
