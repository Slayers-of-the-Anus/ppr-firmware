# Тест управления двигателем шириной импульса

Открой `ESP32_GPIO19_MotorPulseTest.ino` в Arduino IDE. Скетч рассчитан на обычный ESP32 и пакет **esp32 by Espressif Systems 3.x**, установленный в проекте. Дополнительные библиотеки не нужны. Аппаратный LEDC непрерывно формирует сигнал, включая время пауз в программе.

**Выход сигнала — GPIO19, уровень HIGH — 3,3 В.** Если вход вашего контроллера действительно принимает 3,3–5 В, преобразователь уровня для этого сигнала не требуется.

| Подключение | Назначение |
| --- | --- |
| ESP32 GPIO19 | Управляющий сигнальный вход контроллера двигателя |
| ESP32 GND | Общая земля с контроллером |
| Силовое питание контроллера и двигателя | Соответствующий внешний источник питания |

GPIO19 передаёт только управляющий сигнал. Двигатель нельзя подключать непосредственно к GPIO. Указанные ширины импульса относятся к исследованному вами контроллеру: обычный L298N сам по себе не интерпретирует 1400 мкс как нейтраль и не выбирает направление по таким значениям. Если прежний L298N остаётся подключённым, скетч удерживает ENA/ENB на GPIO32/GPIO23 в LOW при снятых перемычках ENA/ENB.

## Сигнал и цикл

По умолчанию частота **100 Гц**, период **10 мс**. Значения — длительность HIGH, а не процент заполнения:

| Команда | Длительность HIGH |
| --- | --- |
| Нейтраль | 1400 мкс = 1,400 мс |
| Вперёд | 1418 мкс = 1,418 мс |
| Назад | 1374 мкс = 1,374 мс |

После включения выдаётся нейтраль 5 секунд, затем бесконечно повторяется: вперёд 3 секунды → нейтраль 2 секунды → назад 3 секунды → нейтраль 2 секунды. Нейтраль — это продолжающиеся импульсы 1400 мкс, а не отключение PWM.

Для проверки на 200 Гц поменяй `PWM_FREQUENCY_HZ` с `100` на `200`. Скетч пересчитывает заполнение, сохраняя заданную длительность HIGH. Установлена разрядность 14 бит: шаг длительности около 0,61 мкс на 100 Гц и 0,305 мкс на 200 Гц; округление до ближайшего шага меньше 0,31 мкс. Значения в Serial Monitor — заданные параметры, а не измерение осциллографом. Работа на других частотах этим скетчем не предполагается.

Serial Monitor: **115200 baud**. Чтобы остановить автоматический цикл, отключи силовое питание двигателя. Перед включением освободи привод/подними колёса: движение начнётся автоматически.

Основная прошивка и предыдущие тестовые скетчи сохранены в своих папках. Этот скетч не меняет NVS. После проверки загрузи основной скетч повторно; для сохранения его настроек оставь `Erase All Flash Before Sketch Upload` выключенным.

Скетч подготовлен без компиляции, загрузки на плату и запуска тестов.

API: [официальная документация Arduino ESP32 LEDC](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/ledc.html).
