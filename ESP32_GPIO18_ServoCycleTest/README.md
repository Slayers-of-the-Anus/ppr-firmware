# Циклічний тест серво на GPIO18

Відкрий `ESP32_GPIO18_ServoCycleTest.ino` в Arduino IDE. Потрібна бібліотека **ESP32Servo**, як і для основної прошивки PhonePilot.

Після ввімкнення плата ставить серво на 90°, чекає 3 секунди та безкінечно повторює рух **60° → 120° → 60°**. Рух відбувається кроками по 1° кожні 20 мс; на крайніх позиціях є пауза 1 секунду. Для завершення вимкни живлення.

Діапазон обмежений для першого запуску: перед увімкненням переконайся, що механізм вільно рухається в цих межах. `MIN_ANGLE`, `MAX_ANGLE`, `CENTER_ANGLE`, швидкість кроків та паузи змінюються на початку скетча. Якщо серво впирається або гуде, вимкни живлення й звузь діапазон.

| Підключення серво | Куди підключити |
| --- | --- |
| Сигнал | ESP32 GPIO18 |
| Живлення «+» | Окреме джерело з напругою, що відповідає серво |
| GND | Мінус джерела та ESP32 GND — спільна земля |

Не живи серво від GPIO чи 3V3 ESP32. Якщо L298N залишається підключеним, скетч утримує його ENA/ENB на GPIO32/GPIO23 у LOW; для цього перемички ENA/ENB мають бути зняті, як у схемі основного проєкту.

Serial Monitor: **115200 baud**. Показує напрям руху, цільовий кут і паузи. Значення кутів — задані команди, а не вимірювання фактичного положення серво.

Це окрема прошивка без телефона, сервера, Wi-Fi чи Bluetooth. Основна прошивка залишається в `../PhonePilotRobot_ESP32/`, тест двигуна — у `../ESP32_L298N_MotorCycleTest/`. Після тесту завантаж основний скетч повторно, щоб повернути PhonePilot. Цей скетч не змінює NVS; залиш `Erase All Flash Before Sketch Upload` вимкненим, щоб зберегти налаштування.

Скетч не компілювався, не завантажувався на плату й не запускався.
