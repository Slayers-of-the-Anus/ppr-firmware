# Окремий тест двигуна: ESP32 + L298N

Відкрий `ESP32_L298N_MotorCycleTest.ino` в Arduino IDE та завантаж на ESP32. Додаткові бібліотеки не потрібні. Цей скетч працює самостійно, без телефона, сервера, Wi-Fi, Bluetooth чи серво.

Після подачі живлення плата чекає 5 секунд, а потім безкінечно повторює:

1. Вперед — 3 секунди.
2. Вимкнення моторів — 2 секунди.
3. Назад — 3 секунди.
4. Вимкнення моторів — 2 секунди.

Мотори працюють на повній потужності виходу драйвера, без регулювання швидкості. Під час пауз ENA/ENB вимкнені, тому мотор зупиняється за інерцією. Перед увімкненням підніми колеса над поверхнею. Для завершення циклу вимкни живлення.

| ESP32 | L298N |
| --- | --- |
| GPIO25 | IN1 |
| GPIO26 | IN2 |
| GPIO27 | IN3 |
| GPIO33 | IN4 |
| GPIO32 | ENA — зняти перемичку |
| GPIO23 | ENB — зняти перемичку |
| GND | GND драйвера та мінус живлення моторів |

Один двигун підключи до OUT1/OUT2. За потреби другий — до OUT3/OUT4; обидва канали працюють одночасно. Якщо напрям неправильний, поміняй місцями дроти відповідного мотора або його прапорець `MOTOR_A_INVERT` / `MOTOR_B_INVERT` у скетчі.

Живлення двигуна подається на силовий вхід L298N від джерела з напругою, що відповідає двигуну. Логічне живлення модуля підключається згідно з його конфігурацією стабілізатора; перемичка стабілізатора 5V — окрема від ENA/ENB. Не підключай силове живлення чи 5V до GPIO/3V3 ESP32. Рекомендовані резистори 10 кОм від ENA й ENB до GND утримують драйвер вимкненим під час запуску або відсутності живлення ESP32.

Serial Monitor: **115200 baud**. У ньому відображаються етапи FORWARD, STOP, BACKWARD.

Основний скетч PhonePilot збережений окремо в `../PhonePilotRobot_ESP32/`. Завантаження тестового скетча замінить прошивку на платі; щоб повернути PhonePilot, завантаж основний скетч повторно. Тестовий скетч не читає й не змінює збережені налаштування PhonePilot у NVS. У параметрах завантаження Arduino IDE залиш `Erase All Flash Before Sketch Upload` вимкненим, якщо потрібно зберегти ці налаштування.

Скетч підготовлений без компіляції, завантаження на плату й запуску тестів.
